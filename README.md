# Лабораторная работа № 7

## Вариант 19

Программа читает из файла сведения о жёстких дисках:
производитель, модель, объём, скорость вращения и цена.

Она выводит диски с объёмом больше заданного, считает их среднюю цену
и находит самый дешёвый и самый дорогой диск среди всех записей.

## Исходные данные

Создайте файл `input.txt`. Каждую запись пишите с новой строки,
поля разделяйте точкой с запятой. Например:

```text
Seagate;ST1000DM010;1000;7200;4500
Western Digital;WD20EZBX;2000;7200;6500
Toshiba;HDWD110;1000;7200;4200
Seagate;ST4000DM004;4000;5400;9500
Western Digital;WD5000AAKX;500;7200;3000
```

Порядок полей: производитель; модель; объём в ГБ; скорость в об/мин; цена в рублях.
Заголовок добавлять не нужно. Допускается не более 100 записей.

## Запуск

1. Откройте `main.cpp` в проекте C++ в Visual Studio.
2. Запустите программу.
3. Введите путь к входному файлу, путь к файлу отчёта и порог объёма — каждое значение с новой строки.

Если `input.txt` находится в рабочей папке программы, можно ввести:

```text
input.txt
output.txt
1000
```

Если появляется `ERROR input`, укажите полный путь к существующему входному файлу.
Пути вводите без кавычек. Для отчёта используйте другой файл.

## Результат

Отчёт выводится на экран и сохраняется в выходной файл.
Для примера выше при пороге 1000 ГБ будут выбраны 2 диска,
их средняя цена составит 8000 рублей.

Если подходящих дисков нет, программа выводит `EMPTY`,
а вместо средней цены — `NONE`.
При ошибке в данных выводится номер строки: `ERROR line N`.
